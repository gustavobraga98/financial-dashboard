## Project Overview

This project is a financial dashboard that allows users to track their expenses, income and balance over time. It is aimed to be used by a single user and does not require authentication and it will try to keep it simple and easy to use.

## Core features

- Expense tracking
- Income tracking
- Balance tracking
- Balance over time

## Tech stack

- FastAPI
- MySQL
- Streamlit for UI

## Package management

We will use uv as our package manager. It must be used to install, uninstall and update packages.
