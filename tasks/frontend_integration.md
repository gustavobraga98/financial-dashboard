# Frontend Integration Task

Connect the Streamlit frontend to the FastAPI backend and build the user interface.

## Objectives
- Create a client/service to fetch data from the FastAPI backend.
- Build a form to add new transactions (Income/Expense).
- Display a table or list of recent transactions.
- Implement charts for "Balance over time" and "Spending by category" using Streamlit's built-in charts or Plotly.
- Ensure all text remains in Portuguese (pt-BR).
